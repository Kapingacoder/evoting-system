Import Guidelines
  • Required columns: Full Name, Admission Number
  • Optional columns: Email (and any additional columns will be ignored)
  • Column matching: The system finds columns by header name (case-insensitive)
  • Supported formats: .xlsx, .xls, .csv
  • Username: Admission Number will be used as the username for login
  • Password: All imported voters will have the default password: first123
  • Password encryption: All passwords are securely encrypted using BCrypt before saving
  • File format: First row must contain headers (Full Name, Admission Number, Email)
  • Example row: "John Doe", "ADM001", "john@example.com"
